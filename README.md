# \# MYTHOS 🐉

# 

# \### Beyond Imagination. Into Creation.

# 

# MYTHOS is a 3D Fantasy Creature Generative AI research project focused on learning and generating original mythical creatures such as dragons, demons, hydras, wyverns and fantasy monsters.

# 

# \## Project Goals

# 

# \- Build a curated dataset of 3D fantasy creatures.

# \- Learn 3D shape representations using Variational Autoencoders (VAEs).

# \- Explore conditional generation of fantasy creature categories.

# \- Study diffusion-based generative models.

# \- Generate and visualize novel 3D creatures.

# 

# \## Technologies

# 

# \- Python

# \- PyTorch

# \- 3D Mesh Processing

# \- Voxel Representations

# \- Variational Autoencoders

# \- Conditional Diffusion Models

# \- Kaggle GPU
